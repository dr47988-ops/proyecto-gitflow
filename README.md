# Proyecto GitFlow

## Descripción

Demo práctica de GitFlow para la exposición del curso Programación en Ambiente Web I.

Este proyecto demuestra la implementación del modelo de ramificación GitFlow utilizando Git y GitHub. Se muestra la creación de ramas de desarrollo y funcionalidades, la realización de commits descriptivos y la integración de cambios mediante merges.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Estructura de ramas

- main: versión estable del proyecto.
- develop: rama de desarrollo.
- feature/contacto: desarrollo del formulario de contacto.

## Cómo ejecutar el proyecto

1. Clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar el archivo `index.html` en un navegador.

## Funcionalidades

- Formulario de contacto.
- Botón de envío.
- Mensaje de confirmación mediante JavaScript.
